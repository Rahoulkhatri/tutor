How to Run the Application

Step 1: Download All Files
  1. Download all files from v0 (click three dots → Download ZIP)
  2. Extract the ZIP file to a folder on your computer
  3. Folder structure should look like:
    tutorconnect-platform/ ├── index.html ├── login.html ├── signup.html ├── student-dashboard.html ├── search-tutors.html ├── teacher-dashboard.html ├── chat.html ├── payments.html ├── admin-commissions.html ├── css/ │ ├── style.css │ ├── auth.css │ ├── dashboard.css │ ├── search.css │ ├── chat.css │ ├── payments.css │ ├── teacher-dashboard.css │ └── admin-commissions.css ├── js/ │ ├── main.js │ ├── auth.js │ ├── dashboard.js │ ├── search.js │ ├── chat.js │ ├── payments.js │ └── teacher-dashboard.js └── SETUP-GUIDE.html
Step 2: Choose Your Setup Method

Pick one of the methods below to run your application:

Method 1: Using Python (Recommended for Windows)

  1. Open Command Prompt or PowerShell in your project folder
  2. Check Python version: python --version
  3. Run one of these commands:
    # Python 3.9+ python -m http.server 8000 # Python 3.8 and earlier python -m SimpleHTTPServer 8000
  4. Open your browser and go to: http://localhost:8000

Method 2: Using Node.js

  1. Install Node.js from https://nodejs.org/ (if not already installed)
  2. Open terminal in your project folder
  3. Install http-server globally:
    npm install -g http-server
  4. Run the server:
    http-server -p 8000
  5. Open browser and go to: http://localhost:8000

Method 3: Using VS Code Live Server (Easiest)

  1. Install "Live Server" extension in VS Code (search in Extensions tab)
  2. Right-click on index.html file
  3. Select "Open with Live Server"
  4. Your browser will automatically open with the application running
  5. Any changes you save will automatically refresh the page
⚠️ Important: Do NOT double-click HTML files directly! You must run them through a local server. Otherwise, CSS and JavaScript won't load properly due to browser security restrictions.

Troubleshooting

Issue: CSS not loading

✓ Solution: Make sure you're running through a local server (http://localhost), not by double-clicking the HTML file

Issue: JavaScript errors in console

✓ Solution: Open browser DevTools (F12), check the Console tab for error messages

Issue: Port 8000 already in use

✓ Solution: Use a different port number: python -m http.server 3000
